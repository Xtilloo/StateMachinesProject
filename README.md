# StateMachinesProject F´ project

## Overview

This project was built for the advanced F-Prime workshop held at SmallSat 2026. The workshop focused on designing and implementing FPP state machines using the MPU-6050 IMU as an example sensor. This sensor has an initialization, configuration, and reading phase - perfect for a state machine.

## Repo Structure

The implementation + helpers are found under `StateMachinesProject/Components/IMUManager/`
